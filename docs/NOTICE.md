# Attribution

UltraDictate is developed by [m0rvey](https://github.com/m0rvey).

UltraDictate is derived from and builds upon [SuperDictate](https://github.com/shlgd/SuperDictate) and [Parakey](https://github.com/rcourtman/parakey) (originally created by Richard Courtman, distributed under the MIT License).

The original copyright notices and licenses are preserved in `LICENSE`.

UltraDictate includes:
- Cross-platform architecture adding native Windows support powered by DirectML and ONNX Runtime.
- Modular component architecture and optimization for Apple Silicon Neural Engine (ANE).
- Enhanced privacy, prompt injection protection, and local Ollama/LM Studio AI cleanup support.
- Multilingual and voice command extensions.

The Parakeet speech model on macOS is loaded through [FluidAudio](https://github.com/FluidInference/FluidAudio). Third-party package licenses remain available through their respective upstream projects.
